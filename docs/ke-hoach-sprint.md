# Ke Hoach Cong Viec Theo Sprint

## 1) Gia dinh lap ke hoach

- Do dai sprint: 2 tuan
- Nhom: 1 PM/PO, 2 Backend, 2 Frontend, 1 QA
- Muc tieu quy: nang cao chat luong extraction va trai nghiem dashboard/chatbot

## 2) Sprint roadmap de xuat (6 sprint)

## Sprint 1 - On dinh nen tang extraction

- Muc tieu:
  - Chuan hoa API extraction va xu ly loi
  - Cai thien UI upload text/PDF
- Deliverables:
  - Refactor response schema extraction
  - Bao loi than thien tren frontend
  - Bo test API extraction co 10+ test case
- KPI:
  - Ti le request extraction thanh cong >= 98% tren staging

## Sprint 2 - Nang cap graph va relation

- Muc tieu:
  - Tang do chinh xac relation
  - Bo sung co che review relation
- Deliverables:
  - Rule relation version 2
  - UI sua/xoa/them relation
  - Export relation ra CSV/JSON
- KPI:
  - Giam 30% so relation sai qua bo mau danh gia

## Sprint 3 - Metrics va insight

- Muc tieu:
  - Tang gia tri phan tich cho nguoi dung cuoi
- Deliverables:
  - Them bo chi so graph nang cao
  - Insight report theo mau co cau truc
  - Download report Markdown/PDF
- KPI:
  - 80% user test danh gia insight "de hieu" tro len

## Sprint 4 - Chatbot va RAG

- Muc tieu:
  - Cai thien do chinh xac cau tra loi theo ngu canh graph
- Deliverables:
  - Toi uu retrieval strategy (hybrid scoring)
  - Prompt template theo nhom intent
  - Logging chat turn-level de danh gia chat luong
- KPI:
  - Tang 20% ti le tra loi dung tren bo cau hoi noi bo

## Sprint 5 - Bao mat va van hanh

- Muc tieu:
  - San sang cho moi truong pre-production
- Deliverables:
  - Auth/JWT cho API quan trong
  - Audit log hanh dong nguoi dung
  - Monitoring dashboard va canh bao co ban
- KPI:
  - 100% endpoint nhay cam co xac thuc

## Sprint 6 - Toi uu hieu nang va release

- Muc tieu:
  - Chot chat luong phien ban release
- Deliverables:
  - Performance tuning extraction/chat
  - Regression test E2E
  - Tai lieu release + runbook van hanh
- KPI:
  - Dat SLA muc tieu, khong blocker bug khi UAT
